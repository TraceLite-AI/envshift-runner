# 后续 GUI 候选池（仅设计，未实测，不计入完成题数）

GUI 可以继续扩展，但题目数量不等于独立环境机制数量。以下每项仍需可执行环境、正反对照、同模型跨环境轨迹。

| 候选 | 具体任务 | 需抓住的错误 |
|---|---|---|
| 原生打印 | 从同一报表打印第 2–3 页到 PDF | 导出全部页、只打印当前页、文件未落盘 |
| 下载冲突 | 保存最新版报表并替换旧文件 | 新文件自动加编号而目标仍为旧版 |
| 文件重命名 | 保留扩展名给三份附件改名 | 隐藏扩展名导致双扩展名或改错类型 |
| 多窗口复制 | 将订单号从参考窗口填入后台 | 复制错记录、焦点落到另一个输入框 |
| 可编辑表格 | 修改指定单元格并应用整列公式 | 只改显示格式、错误填充范围 |
| 日期区间 | 调整跨月订房起止日期 | 日期控件的月/日分段与实际保存不一致 |
| 带横向滚动的表格 | 修改最右侧审批人列 | 滚动后行对应关系错位 |
| 嵌套滚动 | 在侧栏中找到特定记录并提交 | 滚动了主页面，或读到截断内容 |
| 树形文件选择 | 选子文件夹内的指定版本 | 父目录同名文件被误选 |
| 自定义组合框 | 查找同名但不同编号的供应商 | 输入文字未确认选项，实体 ID 未改变 |
| 多语言输入 | 在允许粘贴的 GUI 接口中填写带重音客户名 | ASCII 输入限制与模型任务失败混淆，须先验证通道 |
| 富文本编辑 | 保留链接并修改指定段落 | 看似粘贴成功但链接或段落丢失 |
| 过滤后撤销 | 取消一次错误批量变更，再重做正确范围 | 撤销只作用于最后单项或选区变化 |
| 草稿恢复 | 从已有草稿继续并正式发送到本地模拟收件箱 | 新建重复记录，或仅保存草稿 |
| 权限对话框 | 在测试文件夹授权后导出文件 | 权限弹窗关闭即误判完成；须隔离启动权限噪声 |
| 响应式导航 | 在窄窗口找到折叠菜单内的同一功能 | 看不到入口便跳过步骤；需控制窗口尺寸因果验证 |
| 多显示器坐标 | 将窗口移至第二显示器后完成任务 | 截图与逻辑坐标映射失配；先排除执行器缺陷 |
| 右键菜单 | 对正确条目执行复制或移动 | 菜单打开后上下文对象变化 |
| 关闭未保存页 | 完成编辑并处理离开确认框 | 误点放弃导致服务器仍是旧值 |
| 文件拖入上传区 | 拖入三份正确附件并最终提交 | 拖到了页面其他位置或附件重复 |
