# Retained GUI badcases

INDEX.json includes the original G01 file activation case and all retained G05–G10 failures. New evidence.tar.xz archives contain original screenshots, actions, final state, and a SHA256 manifest. The original G01 evidence.zip remains unchanged. Extract new archives with tar -xJf evidence.tar.xz. A later recovery does not delete a failure. These observations do not establish stable OS-specific mechanisms; see experiments/G05-G10-GUI/REPORT.md for matched trials and interface versions.
